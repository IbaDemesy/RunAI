# Ressources des partenaires

Résumé des documents du « Computer Use Agents Hackathon ». Les liens ci-dessous ont été extraits des PDF avec `pypdf`.
Les codes promotionnels restent uniquement dans les PDF : aucun n’est reproduit ici.

## Devin

Assistant de développement permettant de déléguer des tâches de programmation à un agent.

- Document : [guide du hackathon](devin_hackathon_guide.pdf).
- Liens : [accès à Devin](https://app.devin.ai), [page du hackathon](https://www.trydevin.ai/computer-use-agents-hackathon), [guide d’utilisation](https://app.notion.com/p/Using-Devin-at-the-Computer-Use-Agents-Hackathon-3fc25733fa7a801583ebef5edfa64fd6?source=copy_link).
- Crédits : offre de 200 $ décrite dans le guide ; vérifier la remise et l’activation avant tout paiement.

## H Company

API d’agents pour automatiser des tâches, notamment la navigation web, avec des outils et des compétences personnalisables.

- Documents : [prise en main](h_company_get_started.pdf), [documentation technique](h_company_agents_api_docs.pdf).
- Liens : [inscription](https://platform.hcompany.ai/auth/signup), [démarrage rapide](https://hub.hcompany.ai/agents-api/overview#quickstart), [compétences](https://hub.hcompany.ai/agents-api/skills/overview), [outils personnalisés](https://hub.hcompany.ai/agents-api/custom-tools), [démonstrations](https://github.com/hcompai/agents-api-demos).
- Crédits : aucun montant précisé dans les documents textuels extraits ; vérifier les conditions auprès du partenaire.

## Gladia

API de transcription de la parole en direct ou à partir de fichiers audio, avec des outils d’intégration pour les agents.

- Documents : [crédits du hackathon](gladia_hackathon_credits.pdf), [documentation technique](gladia_technical_docs.pdf).
- Liens : [documentation](https://docs.gladia.io), [démarrage rapide en direct](https://docs.gladia.io/chapters/live-stt/quickstart), [fichiers préenregistrés](https://docs.gladia.io/chapters/pre-recorded-stt/quickstart), [compte](https://app.gladia.io), [facturation](https://app.gladia.io/billing).
- Crédits : 1 000 crédits annoncés pour le hackathon, sous réserve des conditions Gladia ; instructions d’activation dans le PDF.

## Linkup

Service de recherche web permettant aux agents de récupérer des informations pour leurs réponses.

- Documents : [crédits du hackathon](linkup_hackathon_credits.pdf), [documentation technique](linkup_technical_docs.pdf).
- Liens : [documentation et introduction](https://docs.linkup.so/pages/documentation/get-started/introduction), [tableau de bord](https://app.linkup.so/home).
- Notes d'intégration pour RunAI : [docs/LINKUP.md](../docs/LINKUP.md).
- Crédits : 20 $ gratuits à l’inscription et 25 $ supplémentaires via l’offre du hackathon. Le document indique 5 $ pour 1 000 requêtes, soit environ 5 000 requêtes pour 25 $.

## Stripe

Plateforme de paiements pour intégrer des transactions à une application.

- Document : [crédits Stripe](stripe_credits.pdf).
- Lien : [offre et instructions du hackathon](https://stripe.com/startup-benefits/computer-use-agents-hackathon).
- Crédits : offre de 250 $, à réclamer selon les instructions et conditions de la page partenaire.
